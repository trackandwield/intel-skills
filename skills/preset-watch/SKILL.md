# Preset watch

**Status:** designed · **Needs:** search terms from company-setup, the collected store

## How it works

A preset (a company, person or focus area) becomes a standing query against everything collected: articles,
transcripts, captions and posts. Passing mentions buried in longer content count too. Several presets run side by
side, each with its own feed.

## Output

A feed per preset (source, date, the passage that mentions it, link), an alert on each new mention, and a
searchable history.
