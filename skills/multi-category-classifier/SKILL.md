# Multi-category classifier

**Status:** designed · **Needs:** landscape-taxonomy

## How it works

Check each item against the whole taxonomy rather than picking one bucket. A product can be "agent orchestration",
"developer tooling" and "workflow automation" at once, and each tag records the evidence for it.

## Output

The item's full set of categories, each with evidence.
